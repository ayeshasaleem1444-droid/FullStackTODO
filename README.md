# FullStackTODO

A full-stack Todo app with **React** frontend and **FastAPI + PostgreSQL** backend (coming soon).

## 📁 Project Structure

FullStackTODO/
├── todo-frontend/ # React frontend
└── todo-backend/ # FastAPI backend (in progress)

text

## 🛠️ Tech Stack

**Frontend:**

- React (Vite)
- Plain CSS

**Backend:** (in progress)

- FastAPI
- SQLAlchemy
- PostgreSQL

## 🚀 Getting Started

### Frontend

```bash
cd todo-frontend
npm install
npm run dev

## Architecture
- Frontend: React + Vite app in todo-frontend/
- Backend: FastAPI app in todo-backend/
- Database: PostgreSQL, accessed from the backend via SQLAlchemy
- The frontend talks to the backend over HTTP (REST)
```
